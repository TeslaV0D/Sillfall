## English (default language)

Short description (under 270 characters):

```
Animated weather on top of your open windows. Clicks pass through.
```

Description:

```
Sillfall draws rain, snow, fog, falling leaves, sunlight and grass on top of your open windows. The weather lands on window edges, slides off when a window closes, and gets out of the way for a full-screen game, the lock screen and the Start menu. Clicks pass through.

Follow the real weather if you want to. The location sent to the weather service is rounded to about 11 km, and only while sync is on. City search works offline. Nothing else leaves the PC: no accounts, no ads, no analytics.

Visitors sometimes walk along a window. Collect them into a local album. The tray icon switches the weather without opening a window.
```

What's new in this version:

```
First release. Rain, snow, fog, sunlight, leaves and grass, a tray and settings window, optional weather sync, visitors, English and German.
```

## German

Short description:

```
Animiertes Wetter über deinen offenen Fenstern. Klicks gehen hindurch.
```

Description:

```
Sillfall zeichnet Regen, Schnee, Nebel, Laub, Sonnenlicht und Gras über die offenen Fenster. Das Wetter liegt auf den Kanten, rutscht herunter, wenn ein Fenster zugeht, und macht Platz für ein Vollbildspiel, den Sperrbildschirm und das Startmenü. Klicks gehen hindurch.

Auf Wunsch folgt es dem echten Wetter. Der Standort, der an den Wetterdienst geht, ist auf etwa 11 km gerundet, und nur solange der Sync an ist. Die Städtesuche funktioniert offline. Sonst verlässt nichts den PC: kein Konto, keine Werbung, keine Analyse.

Ab und zu läuft ein Besucher an einem Fenster entlang. Einsammeln geht in ein lokales Album. Das Symbol im Infobereich schaltet das Wetter, ohne ein Fenster zu öffnen.
```

What's new in this version:

```
Erste Version. Regen, Schnee, Nebel, Sonnenlicht, Laub und Gras, Infobereich und Einstellungen, optionaler Wetter-Sync, Besucher, Englisch und Deutsch.
```
