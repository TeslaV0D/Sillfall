# Manual checklist M9 – UI, settings, runtime policy

Already automated (Core tests, CI):

- Settings v2: save, load, migrate from v1, sanitize bad values,
- random mode: stays in range, smooth, seed reproducible,
- templates: file and link round-trip; malicious links and inflate bombs rejected,
- runtime policy: smoothness, battery, reduced motion, foreground app,
- per-monitor opacity, hide-over-app rule (WARP),
- runner: all effects, tray icon, system state, every settings page and flyout as images (`previews`, `settings` folder).

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```
