# Manuelle Checkliste M9 – Oberfläche, Einstellungen, Laufzeitregeln

Automatisch geprüft (Core-Tests, CI):

- Einstellungen v2: speichern, laden, Migration von v1, Bereinigung kaputter Werte,
- Zufallsmodus: bleibt im Bereich, gleitet ohne Sprünge, reproduzierbar mit Seed,
- Vorlagen: Datei und Link hin und zurück, schädliche Links und „Inflate-Bomben“ werden abgelehnt,
- Laufzeitregeln: Smoothness, Akku, Reduced Motion, App im Vordergrund,
- Deckkraft pro Monitor, App-Regel „ausblenden“ (WARP),
- auf dem Runner: alle Effekte wie bisher, Tray-Icon, Systemzustand, und jede Einstellungsseite plus Flyout
  als Bild (Artefakt `previews`, Ordner `settings`).

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

## 1. Tray und Flyout

- [ ] Linksklick aufs Tray-Icon öffnet das Flyout unten rechts über der Taskleiste.
- [ ] Klick daneben schließt es.
- [ ] Die Kacheln schalten Effekte an und aus, die Regler ändern die Stärke sofort.
- [ ] Wind-Regler und Vorlagen-Auswahl wirken.
- [ ] „More settings…“ öffnet das Einstellungsfenster.
- [ ] Das Flyout sieht aus wie die Windows-Schnelleinstellungen (Acrylic, abgerundet). Was stört?

## 2. Einstellungsfenster (alle 10 Seiten)

- [ ] **Effekte:**
  - [ ] Intensität, Modus „Random“ (Min, Max, Minuten), Helligkeit.
  - [ ] Eigene Farbe (ColorPicker), Regen-Tiefe, Sonnenseite, Wind.
  - [ ] Alles wirkt live.
- [ ] **Vorlagen:**
  - [ ] Presets anwenden, eigene speichern und löschen.
  - [ ] „Copy link“, dann Link im Feld „Open a shared template“ einfügen: wird angewendet.
  - [ ] Export und Import als `.wscene`.
- [ ] **Sound:** An/Aus und Lautstärke wirken auf den Regen-Sound.
- [ ] **Displays** (mehrere Monitore):
  - [ ] Ein Monitor aus: dort kein Wetter.
  - [ ] Intensität 30 %: dort schwächer.
- [ ] **Apps:**
  - [ ] Regel „Pause while in the foreground“ für z. B. notepad.exe: Notepad in den Vordergrund holen, das Wetter pausiert, Hinweis erscheint.
  - [ ] Regel „Hide the weather over its windows“: Über diesem Programm kein Wetter.
- [ ] **Leistung:**
  - [ ] Live-Zahlen erscheinen.
  - [ ] „Least energy“ senkt auf 30 fps.
  - [ ] Akkubetrieb (Laptop): „Reduce“ halbiert, „Pause“ pausiert.
- [ ] **Erweitert:**
  - [ ] „Hide from screenshots“ wirkt (Snipping Tool).
  - [ ] Autostart an, abmelden, anmelden: Die App läuft im Tray ohne Fenster.
  - [ ] Reduced Motion: Windows-Einstellung „Animationen anzeigen“ aus, das Wetter pausiert mit „Follow Windows“.
  - [ ] „Reset“ setzt zurück, eigene Vorlagen bleiben.
  - [ ] Diagnosefenster öffnet sich.
- [ ] **Info:** Datenschutztext und Credits passen.

## 3. Eine Instanz und Links

- [ ] App ein zweites Mal starten: kein zweites Tray-Icon, das Einstellungsfenster der ersten kommt nach vorn.
- [ ] Einen kopierten `weatherly://`-Link in Win+R einfügen: Die laufende App wendet die Vorlage an.

## 4. Einstellungen überleben

- [ ] Vieles ändern, „Quit“, neu starten: Alles ist wie vorher (Datei `%LOCALAPPDATA%\Weatherly\settings.json`).
