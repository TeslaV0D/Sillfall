# Manuelle Checkliste M6 – Laub

Automatisch geprüft:

- Budget, Landen auf Fenstern und Boden, höchstens 4 Blätter pro 100 px,
- Mitwandern mit dem Fenster,
- Schütteln wirft ab, ohne dass die Blätter zurückfallen,
- Schließen lässt die Blätter auf den Boden fallen,
- schnelle Maus bläst weg, langsame nicht,
- Ausblenden und Stopp nach dem Ausschalten, ferne Blätter hinter Fenstern, eigene Farbe,
- 0 Allokationen pro Frame,
- Golden-Images `leaves-light`, `leaves-windy`, `leaves-close-up`,
- auf dem Windows-Runner: Render-Loop mit Laub und ein Screenshot-Vergleich mit und ohne Laub.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

„Leaf intensity“ hochziehen oder im Tray „Leaves“ wählen. Demo ohne Warten:

```bash
dotnet run --project tools/Weatherly.Sandbox -p:Platform=x64 -- --effect=leaves --scatter-leaves
```

## 1. Optik

- [ ] Blätter wirken wie Blätter: Form, Farben, Größe.
- [ ] Das Flattern sieht natürlich aus: Pendeln, Wenden, kein Zittern.
- [ ] Liegende Blätter liegen glaubhaft auf der Kante, nicht schwebend und nicht im Fenster versunken.
- [ ] Bei 100 % ist es herbstlich, aber nicht zugeschüttet.
- [ ] Was nicht gefällt, konkret notieren.

## 2. Interaktion (echte Fenster)

- [ ] Maus schnell über eine Fensterkante mit Blättern ziehen: Sie fliegen auf.
      **Bitte prüfen:** Reagieren die Blätter bei normalem Arbeiten schon (zu empfindlich) oder erst bei
      sehr hektischen Bewegungen (zu träge)? Siehe ADR-0009, Punkt 5.
- [ ] Fenster schütteln: Die Blätter fliegen weg.
- [ ] Fenster verschieben: Die Blätter wandern mit.
- [ ] Fenster schließen oder minimieren: Die Blätter fallen herunter.
- [ ] Laub aus: Die liegenden Blätter verblassen, danach ist alles ruhig.
