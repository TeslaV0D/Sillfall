# Manual checklist M6 – Leaves

Already automated:

- Budget, land on windows and ground, max 4 leaves per 100 px,
- move with window,
- shake throws off without leaves falling back on same window,
- close drops leaves to ground,
- fast mouse gust, slow mouse no gust,
- fade and stop after turn-off, distant leaves behind windows, custom color,
- 0 allocations per frame,
- golden images `leaves-light`, `leaves-windy`, `leaves-close-up`,
- Windows runner: leaves render loop and screenshot compare.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Raise “Leaf intensity” or tray “Leaves”. Demo:

```bash
dotnet run --project tools/Weatherly.Sandbox -p:Platform=x64 -- --effect=leaves --scatter-leaves
```

## 1. Visuals

- [ ] Leaves read as leaves: shape, colors, size. (Preview note: maple may look like a blob at 100%, clearer at 200%. Bigger?)
- [ ] Flutter natural: sway and tumble, no jitter.
- [ ] Resting leaves believable on edge, not floating or sunk into window.
- [ ] 100% autumnal but not buried.
- [ ] Note dislikes.

## 2. Interaction (real windows)

- [ ] Fast mouse over edge with leaves: they lift. **Check:** Too sensitive during normal work or too sluggish? ADR-0009, §5.
- [ ] Shake: leaves fly off.
- [ ] Move window: leaves follow.
- [ ] Close or minimize: leaves fall.
- [ ] Leaves off: resting leaves fade; then quiet.
