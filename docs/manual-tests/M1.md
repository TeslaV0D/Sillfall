# Manuelle Checkliste M1 – Overlay-Spike

M1 legt über jeden Monitor ein transparentes Overlay mit Testmuster. Effekte gibt es noch nicht.

Automatisch geprüft ist schon (CI, Windows-Runner mit einem Monitor):

- Testmuster pixelgenau, bei 100 %, 125 %, 150 % und 200 % Skalierung (WARP),
- jedes Pixel ist gültiges premultiplied Alpha, ungezeichnete Flächen sind voll transparent,
- Overlay-Fenster sitzt exakt auf dem Monitor, hat alle Styles, Hit-Test geht durch, kein Fokus,
- Overlay liegt über dem danach aktivierten App-Fenster (Z-Order und Screenshot),
- im Leerlauf werden keine Frames gezeichnet,
- Screenshot zeigt das Muster, mit Screenshot-Ausschluss nicht.

Was nur auf echter Hardware prüfbar ist, steht hier.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Das Fenster „Weatherly“ zeigt Schalter, Monitorliste und Checks. Alle Checks sollten `OK` sein.

## So sieht das Testmuster aus

- **Magenta Rahmen** genau an den vier Monitorkanten, 2 px bei 100 %.
- **Farbige Ecken:** rot oben links, grün oben rechts, blau unten links, gelb unten rechts.
- **Gitter** in dünnem Grau: eine Zelle ist 100 px bei 100 % (200 px bei 200 %).
- **Türkises Kreuz** in der Mitte.
- **Weißer Verlauf** in der oberen Hälfte: links unsichtbar, rechts deckend weiß.
- **Schwarzer Block** in der unteren Hälfte: dunkelt den Desktop zu 50 % ab.

## 1. Darstellung

- [ ] Auf jedem Monitor erscheint das Muster, der Rahmen berührt alle vier Kanten.
- [ ] Der Desktop ist überall sonst unverändert sichtbar, keine schwarze oder graue Fläche.
- [ ] Der weiße Verlauf läuft weich aus, ohne dunklen Rand am transparenten Ende.
- [ ] Der schwarze Block dunkelt ab und hellt nicht auf.
- [ ] Linien sind scharf, nicht verschwommen.

## 2. Click-Through und Fokus

- [ ] Klick auf ein Fenster unter dem Overlay: das Fenster reagiert (z. B. Text markieren im Editor).
- [ ] Doppelklick auf ein Desktop-Icon öffnet es.
- [ ] Scrollen mit dem Mausrad in einem Browser unter dem Overlay funktioniert.
- [ ] Drag & Drop einer Datei im Explorer funktioniert.
- [ ] Während man tippt, bleibt der Fokus im Zielfenster. Das Overlay klaut ihn nie.
- [ ] Alt+Tab und Taskleiste zeigen kein Overlay-Fenster.
- [ ] Rechtsklick auf den Desktop öffnet das Kontextmenü.

## 3. Topmost

- [ ] Das Muster liegt über normalen Fenstern, auch über einem maximierten.
- [ ] Ein anderes Fenster anklicken oder per Alt+Tab wechseln: das Muster bleibt darüber.
- [ ] Taskleiste anklicken: das Muster liegt danach wieder über der Taskleiste.
- [ ] Check „Z-order“ nach „Check again“: `OK`. Falls dort Fenster genannt werden, bitte notieren.
- [ ] Startmenü, Benachrichtigungen und Taskleiste öffnen: notieren, ob das Muster darüber oder
      darunter liegt (beides ist für M1 okay, das Ausblenden kommt in M13).

## 4. DPI und mehrere Monitore

Wenn vorhanden: zwei Monitore mit unterschiedlicher Skalierung (z. B. 100 % und 150 %).

- [ ] Monitorliste zeigt alle Monitore mit richtiger Auflösung, Position und Skalierung.
- [ ] Gitter: bei 150 % sind die Zellen 150 px groß (mit Lineal oder Screenshot prüfen).
- [ ] Monitor links oder über dem Hauptmonitor (negative Koordinaten): Muster sitzt korrekt.
- [ ] Skalierung eines Monitors in den Einstellungen ändern: Muster passt sich innerhalb einer Sekunde an.
- [ ] Auflösung ändern: Muster passt sich an.
- [ ] Monitor abziehen: sein Overlay verschwindet, die anderen bleiben. Checks bleiben `OK` („Check again“).
- [ ] Monitor wieder anstecken: Overlay erscheint wieder.
- [ ] Taskleiste verschieben oder automatisch ausblenden: nichts flackert, Checks bleiben `OK`.

## 5. Screenshot-Ausschluss

- [ ] Schalter „Hide the overlay from screenshots“ an: Win+Shift+S zeigt den Desktop ohne Muster.
- [ ] Gleiches mit Snipping Tool im Videomodus oder OBS.
- [ ] Schalter aus: Muster ist wieder auf Screenshots.

## 6. Leistung

- [ ] Task-Manager, Registerkarte Details, Spalte GPU: `Weatherly.App.exe` liegt bei 0 %,
      solange nichts verändert wird.
- [ ] CPU der App im Leerlauf bei 0 %.
- [ ] Auf einem Laptop mit zwei GPUs: Task-Manager, Spalte „GPU-Engine“ zeigt die integrierte GPU.
      Der Check „Graphics adapter“ nennt sie ebenfalls.

## 7. Overlay an und aus

- [ ] Schalter „Overlay“ aus: Muster verschwindet sofort auf allen Monitoren.
- [ ] Schalter wieder an: Muster erscheint wieder.
- [ ] Fenster schließen: Overlays verschwinden, Prozess beendet sich.

## 8. Robustheit (optional)

- [ ] Sperren (Win+L) und entsperren: Muster ist danach noch da.
- [ ] Energiesparmodus und Aufwachen: Muster ist danach noch da.
- [ ] Grafiktreiber neu starten (Win+Strg+Umschalt+B): Muster erscheint nach kurzem Flackern wieder.
      Check „Overlay errors“ bleibt `OK`. Hinweis: Neu gezeichnet wird bei der nächsten Änderung,
      also notfalls einmal den Overlay-Schalter umlegen. Ergebnis bitte notieren.
- [ ] Per Remotedesktop verbinden: notieren, was passiert (Pausieren kommt in M13).
