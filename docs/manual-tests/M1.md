# Manual checklist M1 – Overlay spike

M1 places a transparent overlay with a test pattern on each monitor. No effects yet.

Already automated (CI, Windows runner, one monitor):

- Test pattern pixel-accurate at 100%, 125%, 150%, and 200% scaling (WARP),
- every pixel valid premultiplied alpha; undrawn areas fully transparent,
- overlay window exactly on the monitor, correct styles, hit-test passes through, no focus,
- overlay stays above the app window activated afterward (Z-order and screenshot),
- no frames drawn when idle,
- screenshot shows the pattern; with screenshot exclusion it does not.

Items that need real hardware are below.

## Start

```bash
dotnet run --project src/Sillfall.App -p:WindowsPackageType=None
```

The “Sillfall” window shows toggles, monitor list, and checks. All checks should be `OK`.

## Test pattern appearance

- **Magenta border** on all four monitor edges, 2 px at 100%.
- **Colored corners:** red top-left, green top-right, blue bottom-left, yellow bottom-right.
- **Grid** in thin gray: one cell is 100 px at 100% (200 px at 200%).
- **Cyan cross** in the center.
- **White gradient** in the upper half: invisible left, opaque white right.
- **Black block** in the lower half: darkens the desktop to 50%.

## 1. Appearance

- [ ] Every monitor shows the pattern; border touches all four edges.
- [ ] Desktop is otherwise unchanged; no black or gray sheet.
- [ ] White gradient fades smoothly without a dark edge at the transparent end.
- [ ] Black block darkens without lifting brightness.
- [ ] Lines are sharp, not blurry.

## 2. Click-through and focus

- [ ] Click a window under the overlay: it responds (e.g. select text in an editor).
- [ ] Double-click a desktop icon opens it.
- [ ] Mouse wheel scroll in a browser under the overlay works.
- [ ] Drag and drop a file in Explorer works.
- [ ] While typing, focus stays in the target window. Overlay never steals it.
- [ ] Alt+Tab and taskbar show no overlay window.
- [ ] Right-click desktop opens the context menu.

## 3. Topmost

- [ ] Pattern sits above normal windows, including maximized.
- [ ] Activate another window or Alt+Tab: pattern stays on top.
- [ ] Click taskbar: pattern is again above the taskbar.
- [ ] “Z-order” check after “Check again”: `OK`. Note any windows listed.
- [ ] Open Start, notifications, taskbar: note whether pattern is above or below (both OK for M1; hiding comes in M13).

## 4. DPI and multiple monitors

If available: two monitors with different scaling (e.g. 100% and 150%).

- [ ] Monitor list shows all monitors with correct resolution, position, and scale.
- [ ] Grid: at 150% cells are 150 px (ruler or screenshot).
- [ ] Monitor left or above primary (negative coords): pattern aligned.
- [ ] Change monitor scaling in Settings: pattern adjusts within about a second.
- [ ] Change resolution: pattern adjusts.
- [ ] Unplug a monitor: its overlay goes away; others stay. Checks stay `OK` (“Check again”).
- [ ] Plug monitor back: overlay returns.
- [ ] Move or auto-hide taskbar: no flicker; checks stay `OK`.

## 5. Screenshot exclusion

- [ ] Toggle “Hide the overlay from screenshots” on: Win+Shift+S shows desktop without pattern.
- [ ] Same with Snipping Tool video mode or OBS.
- [ ] Toggle off: pattern visible on screenshots again.

## 6. Performance

- [ ] Task Manager, Details, GPU column: `Sillfall.App.exe` at 0% while idle.
- [ ] App CPU at 0% when idle.
- [ ] Laptop with two GPUs: “GPU engine” shows integrated GPU. “Graphics adapter” check matches.

## 7. Overlay on and off

- [ ] “Overlay” off: pattern disappears on all monitors immediately.
- [ ] On again: pattern returns.
- [ ] Close window: overlays gone, process exits.

## 8. Robustness (optional)

- [ ] Lock (Win+L) and unlock: pattern still there.
- [ ] Sleep and wake: pattern still there.
- [ ] Restart graphics driver (Win+Ctrl+Shift+B): pattern returns after brief flicker. “Overlay errors” stays `OK`. Note: redraw on next change; toggle overlay if needed.
- [ ] Connect via Remote Desktop: note behavior (pause comes in M13).
