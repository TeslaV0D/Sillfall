# Manual checklist M2 – Window tracking and surfaces

M2 detects open windows and computes visible edges. Debug layer shows them: **top edges green** (two rows just above the window), **sides orange** (two columns left and right), **ground blue** (above the taskbar). No effects yet.

Already automated (CI, Windows runner, one monitor):

- Occlusion and clipping in 36 layouts (overlap, cascade, maximized, multi-monitor, negative coords),
- debug layer pixel-accurate vs computed surfaces (WARP),
- app moves its window; tracking follows exactly; motion event raised,
- desktop screenshot: lines exactly above and beside the app window,
- no drawing when idle.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Turn off “Show the calibration pattern” and on “Show detected surfaces (debug layer)”. All checks should be `OK`, including “Window tracking” and “Surfaces”.

## 1. Lines align with window edges

Use Win+Shift+S and zoom in.

- [ ] Green line directly above the title bar, no gap, no overlap with frame.
- [ ] Orange lines flush left and right of the frame.
- [ ] Same for custom-title windows (browser, VS Code, Teams, Explorer).
- [ ] At 125%, 150%, or 200%: lines thicker (4 px at 200%) and still flush.
- [ ] Blue line directly above the taskbar.

## 2. Occlusion

- [ ] Two overlapping windows: rear top edge ends at the front window.
- [ ] Fully covered window: no lines.
- [ ] Window pushed onto another’s top edge: lower line disappears there.
- [ ] Maximized: no green top line; blue ground occluded.
- [ ] Snap two windows side by side: lines correct on both.

## 3. Motion

- [ ] Drag window: lines follow smoothly (one frame delay OK).
- [ ] Resize: lines update.
- [ ] Minimize and restore: lines go and return.
- [ ] Close: lines disappear.
- [ ] Move to another monitor: lines follow across the boundary.
- [ ] Switch virtual desktop (Win+Ctrl+Arrow): lines show only current desktop windows.

## 4. Edge cases

- [ ] Open Start or Search: note lines (no lines on shell UI expected).
- [ ] Context menus and tooltips: no lines.
- [ ] Store apps (Settings, Calculator): lines correct.
- [ ] Taskbar on left or top: note where blue ground line sits.
- [ ] Auto-hide taskbar: ground line at bottom monitor edge.

## 5. Performance

- [ ] Debug layer on, nothing moving: GPU 0%.
- [ ] Drag window quickly in circles: CPU stays low single digits.
