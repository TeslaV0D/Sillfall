# Manuelle Checkliste M12 – Sprachen und Barrierefreiheit

Automatisch geprüft:

- **Core-Tests:**
  - Beide Sprachdateien sind vollständig und gleich aufgebaut, mit denselben Platzhaltern.
  - Jeder Schlüssel aus dem Code existiert.
  - Hoher Kontrast pausiert, wenn die Einstellung an ist.
- **Smoke-Test:**
  - Jedes per Tab erreichbare Bedienelement auf allen Einstellungsseiten und im Flyout hat einen Namen für Narrator.
  - Die Seiten „Effekte“, „Besucher“ und „Erweitert“ liegen zusätzlich auf Deutsch als Bild in den Previews
    (`settings/settings-de-*.png`).

## 1. Sprache

- [ ] Windows auf Deutsch: Die App startet auf Deutsch (Einstellungen, Flyout, Tray-Menü, Hinweise).
- [ ] „Erweitert → Sprache → English“: Die Seite wechselt sofort, Tray-Menü und Flyout beim nächsten Öffnen.
- [ ] Deutsche Texte passen überall hinein (nichts abgeschnitten, keine Überläufe im Flyout).
- [ ] Gibt es Formulierungen, die holpern? Bitte notieren.

## 2. Narrator (Strg+Win+Eingabe)

- [ ] Mit Tab durch jede Einstellungsseite: Jedes Element wird mit Namen vorgelesen, Regler mit Wert.
- [ ] Flyout: Kacheln heißen „Regen“, die Regler „Regen, Stärke“ usw.
- [ ] Ein Besucher kommt: Fokus auf das Tray-Icon liest Name und Strg+Alt+V vor. Strg+Alt+V sammelt ihn ein, der
      Hinweis wird vorgelesen.
- [ ] Accessibility Insights for Windows (FastPass) auf Einstellungsfenster und Flyout: keine kritischen Befunde.

## 3. Hoher Kontrast (Einstellungen → Barrierefreiheit → Kontrastdesigns)

- [ ] Ein Kontrastdesign an: Das Wetter pausiert, die Einstellungen zeigen den Grund.
- [ ] Einstellungen und Flyout sind in den Kontrastfarben gut lesbar.
- [ ] „Wetter pausieren, solange hoher Kontrast an ist“ aus: Das Wetter läuft weiter.

## 4. Reduced Motion

- [ ] „Animationen anzeigen“ in Windows aus: Das Wetter pausiert (Einstellung „Windows folgen“).

## 5. Teilen

- [ ] Besucher-Seite: „Teilen…“ öffnet das Teilen-Fenster von Windows mit der Karte (z. B. an Mail oder Nearby Share).
