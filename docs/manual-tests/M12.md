# Manual checklist M12 – Localization and accessibility

Already automated:

- **Core tests:**
  - both language files complete and aligned, same placeholders,
  - every key from code exists,
  - high contrast pauses when setting on.
- **Smoke test:**
  - every tab-focusable control on all settings pages and flyout has a Narrator name,
  - Effects, Visitors, and Advanced pages also captured in German in previews (`settings/settings-de-*.png`).

## 1. Language

- [ ] Windows in German: app starts in German (settings, flyout, tray, notices).
- [ ] Advanced → Language → English: page switches immediately; tray/flyout on next open.
- [ ] German strings fit (no clipping, flyout overflow).
- [ ] Awkward wording? Note it.

## 2. Narrator (Ctrl+Win+Enter)

- [ ] Tab through each settings page: every control named; sliders with value.
- [ ] Flyout: tiles “Rain”; sliders “Rain, intensity”, etc.
- [ ] Visitor arrives: tray focus reads name and Ctrl+Alt+V. Ctrl+Alt+V collects; toast read aloud.
- [ ] Accessibility Insights for Windows (FastPass) on settings and flyout: no critical issues.

## 3. High contrast (Settings → Accessibility → contrast themes)

- [ ] Contrast theme on: weather pauses; settings show reason.
- [ ] Settings and flyout readable in contrast colors.
- [ ] “Pause weather while high contrast is on” off: weather continues.

## 4. Reduced motion

- [ ] Windows “Show animations” off: weather pauses (Follow Windows).

## 5. Share

- [ ] Visitors page “Share…” opens Windows share with card (Mail, Nearby Share, etc.).
