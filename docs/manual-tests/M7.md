# Manuelle Checkliste M7 – Nebel und Sonne

Automatisch geprüft:

- Nebel und Sonne blenden ein und aus, der Nebel driftet mit dem Wind,
- der Render-Loop stoppt nach dem Ausschalten,
- Verdecker in der richtigen Reihenfolge, 0 Allokationen pro Frame,
- WARP-Tests: Nebel dünner über Fenstern, dichter unten, nie über der Maximaldeckung; die Sonne glüht um
  sich, Fenster werfen Schatten,
- Golden-Images `fog`, `sun`, `sun-and-fog`,
- auf dem Windows-Runner: Render-Loop und Screenshot-Vergleich für beide.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

„Fog intensity“ und „Sunlight intensity“ hochziehen, oder im Tray „Fog“ und „Sun“ wählen.

## 1. Nebel

- [ ] Der Nebel wirkt wie Nebel und nicht wie ein Grauschleier oder ein Rauschmuster.
- [ ] Er zieht langsam, ohne Ruckeln, und wird nach unten dichter.
- [ ] Text in Fenstern bleibt bei 100 % gut lesbar.
- [ ] Fenster ragen sichtbar heraus: dünnerer Nebel über ihnen, heller Saum an der Oberkante.
- [ ] Ein- und Ausblenden dauert ein paar Sekunden.

## 2. Sonne

- [ ] Die Strahlen kommen aus der Ecke oben rechts, warm und nicht milchig.
      (Aus der Vorschau: Auf dem Runner wirkt das Licht eher hell als warm, und die Schatten der Fenster
      sind dezent. Stärker, wärmer, oder so lassen?)
      **Bitte prüfen:** auf hellem und auf dunklem Hintergrund. Siehe ADR-0010, Punkt 4.
- [ ] Fenster werfen Schatten in die Strahlen. Wenn man ein Fenster verschiebt, wandert der Schatten mit.
- [ ] Glühen an der Sonne, Staub schwebt im Licht.
- [ ] Inhalte in Fenstern bleiben lesbar.

## 3. Leistung (wichtig, das ist der teuerste Effekt)

Bei 1440p oder 4K, Nebel und Sonne auf 100 %:

- [ ] GPU der App im Task-Manager: ______ %
- [ ] Läuft flüssig, ohne Ruckeln beim Fensterziehen: ja / nein
- [ ] Laptop im Akkubetrieb: Lüfter oder Wärme auffällig? ja / nein
