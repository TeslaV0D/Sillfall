# Manual checklist M7 – Fog and sun

Already automated:

- Fog and sun ease in/out; fog drifts with wind,
- render loop stops after turn-off,
- occluders in correct order, 0 allocations per frame,
- WARP: fog thinner over windows, denser below, under max opacity; sun glows, windows cast shadows,
- golden images `fog`, `sun`, `sun-and-fog`,
- Windows runner: render loop and screenshot compare for both.

## Start

```bash
dotnet run --project src/Sillfall.App -p:WindowsPackageType=None
```

Raise “Fog intensity” and “Sunlight intensity”, or tray Fog and Sun.

## 1. Fog

- [ ] Reads as fog, not gray sheet or noise.
- [ ] Drifts slowly without stutter; denser toward bottom.
- [ ] Text in windows readable at 100%.
- [ ] Windows emerge: thinner fog over them, bright rim on top edge.
- [ ] Ease in/out over a few seconds.

## 2. Sun

- [ ] Rays from upper-right corner, warm not milky. (Preview: runner may look bright more than warm; window shadows subtle. Stronger, warmer, or keep?)
      **Check** on light and dark backgrounds. ADR-0010, §4.
- [ ] Windows cast shadows in rays; shadow moves when window moves.
- [ ] Glow at sun; dust in light.
- [ ] Window content still readable.
