# Manuelle Checkliste M8 – Gras

Automatisch geprüft:

- Dichte nach Breite, Wachstum bis zur Maximalhöhe, mit Regen dreimal so schnell,
- Halme stehen auf der Kante und wandern mit dem Fenster, Wind neigt sie, der Cursor drückt sie weg,
- Schließen blendet aus, Resize schneidet oder lässt nachwachsen,
- verdeckte Kanten zeigen kein Gras,
- Ausschalten lässt das Gras verwelken und stoppt den Render-Loop,
- 0 Allokationen pro Frame,
- Golden-Images `grass`, `grass-rain`, `grass-close-up`,
- auf dem Windows-Runner: Render-Loop und Screenshot-Vergleich.

## Start

„Grass intensity“ hochziehen oder im Tray „Grass“ wählen. In der Sandbox schaltet die Taste H Gras an,
schon zu 70 % gewachsen:

```bash
dotnet run --project tools/Weatherly.Sandbox -p:Platform=x64 -- --effect=grass
```

## 1. Optik

- [ ] Die Halme wirken wie Gras: Form, Grüntöne, Büschel.
- [ ] Das Wiegen im Wind ist ruhig und natürlich.
- [ ] Gras auf hellen Fenstern und auf der Taskleiste ist gut zu sehen, stört aber nicht.

## 2. Verhalten

- [ ] Das Wachstum ist sichtbar, aber nicht zu langsam: ausgewachsen nach etwa 20 s, mit Regen schneller.
      **Bitte prüfen:** Passt das Tempo? Siehe ADR-0011, Punkt 3.
- [ ] Der Mauszeiger über einer Kante drückt das Gras zur Seite.
- [ ] Fenster verschieben: Das Gras wandert mit. Fenster schließen: Das Gras blendet kurz aus.
- [ ] Gras aus: Es verwelkt in wenigen Sekunden.
