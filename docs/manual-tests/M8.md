# Manual checklist M8 – Grass

Already automated:

- Density from width, growth to max height, 3× speed with rain,
- blades on edge moving with window, wind tilt, cursor push,
- close fades out, resize trims or regrows,
- occluded edges show no grass,
- turn off withers and stops render loop,
- 0 allocations per frame,
- golden images `grass`, `grass-rain`, `grass-close-up`,
- Windows runner: render loop and screenshot compare.

## Start

Raise “Grass intensity” or tray Grass. In Sandbox, H toggles grass at 70% growth:

```bash
dotnet run --project tools/Sillfall.Sandbox -p:Platform=x64 -- --effect=grass
```

## 1. Visuals

- [ ] Blades look like grass: shape, greens, tufts.
- [ ] Wind sway calm and natural.
- [ ] Visible on light windows and taskbar without clutter.

## 2. Behavior

- [ ] Growth visible but not too slow: full height ~20 s; faster with rain. **Check** pace. ADR-0011, §3.
- [ ] Cursor over edge pushes blades aside.
- [ ] Move window: grass follows. Close: short fade.
- [ ] Grass off: withers in a few seconds.
