# Manuelle Checkliste M0 – Fundament

M0 liefert die Projektstruktur, CI und eine leere WinUI-App. Es gibt noch keine Effekte und kein Overlay.
Automatisch geprüft ist bereits: Build für x64 und ARM64, Core-Tests, Render-Tests mit WARP und der
App-Start auf dem Windows-Runner (Smoke-Test). Diese Liste deckt ab, was nur auf einem echten PC
sichtbar ist.

Voraussetzung: Windows 10 2004 oder neuer, .NET-10-SDK.

## 1. Build

```bash
dotnet build Weatherly.slnx -p:Platform=x64
```

- [ ] Build läuft ohne Warnungen und Fehler durch.

## 2. Tests

```bash
dotnet test --project tests/Weatherly.Core.Tests
```

```bash
dotnet test --project tests/Weatherly.Render.Tests
```

- [ ] Beide Testläufe sind grün.

## 3. App starten

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

- [ ] Ein Fenster „Weatherly“ mit Versionsnummer erscheint.
- [ ] Titelleiste zeigt das Icon (Wolke mit Regentropfen). Unter Windows 11 ist der Hintergrund Mica.
- [ ] Zeile „DPI awareness“ zeigt `OK` und `Per-Monitor V2`.
- [ ] Zeile „Direct3D 11 device“ zeigt `OK` und ein Feature-Level (11.0 oder 11.1).
- [ ] Fenster auf einen Monitor mit anderer Skalierung ziehen: Text bleibt scharf.
- [ ] Icon in der Taskleiste sieht in hellem und dunklem Design sauber aus.

## 4. Optional: paketiert starten

In Visual Studio `Weatherly.slnx` öffnen, Startprojekt `Weatherly.App`, Profil „Weatherly (Package)“, F5.

- [ ] App startet als MSIX-Paket und zeigt dasselbe Fenster.
- [ ] Im Startmenü erscheint „Weatherly“ mit dem App-Icon.
