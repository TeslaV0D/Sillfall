# Manual checklist M0 – Foundation

M0 delivers project structure, CI, and an empty WinUI app. No effects or overlay yet. Already automated: build for x64 and ARM64, Core tests, WARP render tests, and app startup on the Windows runner (smoke test). This list covers what only a real PC can verify.

Prerequisite: Windows 10 2004 or newer, .NET 10 SDK.

## 1. Build

```bash
dotnet build Weatherly.slnx -p:Platform=x64
```

- [ ] Build completes with no warnings or errors.

## 2. Tests

```bash
dotnet test --project tests/Weatherly.Core.Tests
```

```bash
dotnet test --project tests/Weatherly.Render.Tests
```

- [ ] Both test runs are green.

## 3. Start the app

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

- [ ] A “Sillfall” window appears with a version number.
- [ ] Title bar shows the icon (cloud with raindrops). On Windows 11 the background is Mica.
- [ ] “DPI awareness” line shows `OK` and `Per-Monitor V2`.
- [ ] “Direct3D 11 device” line shows `OK` and a feature level (11.0 or 11.1).
- [ ] Drag the window to a monitor with different scaling: text stays sharp.
- [ ] Taskbar icon looks clean in light and dark themes.

## 4. Optional: packaged start

Open `Weatherly.slnx` in Visual Studio, startup project `Weatherly.App`, profile “Weatherly (Package)”, F5.

- [ ] App starts as MSIX package and shows the same window.
- [ ] Start menu lists “Sillfall” with the app icon.
