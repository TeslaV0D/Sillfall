# Manuelle Checkliste M11 – Visitors

Automatisch geprüft:

- **Core-Tests:**
  - Verhalten: Auftauchen, Laufen, Springen, Mitfahren, Fallen, Gehen.
  - Einsammeln über Korb und Tastatur, Schmollen.
  - Requisiten, Planer, Punkte, Combo, Erfolge, Speichern.
  - Sounds; keine Allokationen im Frame-Loop.
- **WARP:** alle Figuren in allen Posen mit allen Requisiten (`render/visitors-sheet.png` in den Previews).
- **Smoke-Test auf dem Runner:**
  - Eine Figur landet auf dem App-Fenster, die Tastatur sammelt sie ein.
  - Im Interaktiv-Modus zieht echte Maus-Eingabe eine Figur in den Korb.
  - Danach bleibt kein Hit-Fenster übrig.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Einstellungen, Seite „Visitors“: Häufigkeit „Often“ und „Invite a visitor now“.

## 1. Besuch

- [ ] Die Figur taucht auf einer Fensteroberkante auf (kurzes Aufploppen), läuft, bleibt mal stehen und blinzelt.
- [ ] Sie fährt mit, wenn das Fenster verschoben wird.
- [ ] Am Ende der Kante springt sie zu einem nahen Fenster oder dreht um.
- [ ] Fenster schütteln oder schließen: Sie fällt und landet auf einem Fenster darunter oder auf der Taskleiste.
- [ ] Bei Regen holt sie einen Schirm heraus. Bei Schnee einen Schneeball, bei Sonne eine Sonnenbrille.
- [ ] Im Lieblingswetter hüpft sie (Pip im Regen, Tuck im Schnee …).
- [ ] Nach etwa einer Minute geht sie von selbst. Danach braucht die App wieder 0 % GPU (Task-Manager).
- [ ] Das Overlay bleibt click-through, auch dort, wo eine Figur läuft (ohne Interaktiv-Modus).

## 2. Einsammeln

- [ ] „Pick up visitors …“ an: Über einer Figur wird der Mauszeiger zur Hand.
- [ ] Ziehen: Die Figur hängt am Zeiger, unten rechts erscheint der Korb.
- [ ] Über dem Korb leuchtet er auf. Loslassen sammelt die Figur ein: Hinweis mit Punkten, Sound (wenn an).
- [ ] Woanders loslassen: Die Figur fällt, schaut böse und läuft schnell weg.
- [ ] Neben der Figur geht jeder Klick weiter an die Fenster darunter, auch direkt nach dem Ziehen.
- [ ] Strg+Alt+V sammelt die erste Figur ein. Das Tray-Menü hat „Collect the visitor“, solange eine da ist.
- [ ] Narrator: Fokus auf das Tray-Icon liest „… is visiting. Press Ctrl+Alt+V …“ vor.
- [ ] Mehrere Monitore: Der Korb steht auf dem Hauptmonitor, Ziehen über Monitorgrenzen klappt.

## 3. Sammlung

- [ ] Die Seite „Visitors“ zeigt Punkte, Anzahl pro Figur (noch nicht getroffene blass), Erfolge mit Häkchen.
- [ ] „Copy card“ legt ein Bild in die Zwischenablage (z. B. in Paint einfügen). „Save card…“ speichert ein PNG.
- [ ] Nach einem Neustart sind Punkte und Sammlung noch da (`%LOCALAPPDATA%\Weatherly\collection.json`).

## 4. Gefühl (Boss-Urteil)

- [ ] Häufigkeit, Tempo, Sprungweite und Besuchsdauer: zu viel, zu wenig, passt?
- [ ] Sounds: zu laut, zu kindlich, passt?
