# Manual checklist M11 – Visitors

Already automated:

- **Core tests:**
  - behavior: appear, walk, jump, ride, fall, leave,
  - collect via basket and keyboard, sulk,
  - props, scheduler, points, combo, achievements, persistence,
  - sounds; no allocations in frame loop.
- **WARP:** all characters in all poses with all props (`render/visitors-sheet.png` in previews).
- **Smoke test on runner:**
  - character lands on app window; keyboard collects,
  - interactive mode drags character to basket with real mouse,
  - no hit windows left afterward.

## Start

```bash
dotnet run --project src/Sillfall.App -p:WindowsPackageType=None
```

Settings, Visitors: frequency “Often” and “Invite a visitor now”.

## 1. Visit

- [ ] Character pops onto a window top edge, walks, stands, blinks.
- [ ] Moves with window when dragged.
- [ ] At edge end jumps to nearby window or turns.
- [ ] Shake or close window: falls to lower window or taskbar.
- [ ] Rain: umbrella. Snow: snowball. Sun: sunglasses, etc.
- [ ] Favorite weather: happy hop (Pip in rain, Tuck in snow, …).
- [ ] Leaves after ~1 minute. Then app GPU 0% in Task Manager.
- [ ] Overlay click-through even where character walks (without interactive mode).

## 2. Collecting

- [ ] “Pick up visitors …” on: hand cursor over character.
- [ ] Drag: character follows; basket bottom-right.
- [ ] Over basket it glows. Release there: collect, points, sound if on.
- [ ] Release elsewhere: falls, sulks, leaves quickly.
- [ ] Clicks beside character still reach windows below, including right after drag.
- [ ] Ctrl+Alt+V collects first character. Tray “Collect the visitor” while one is present.
- [ ] Narrator on tray: “… is visiting. Press Ctrl+Alt+V …”.
- [ ] Multi-monitor: basket on primary; drag across monitors works.

## 3. Collection

- [ ] Visitors page: points, count per character (unmet faded), achievements with checks.
- [ ] “Copy card” to clipboard (paste in Paint). “Save card…” PNG.
- [ ] After restart: points and collection persist (`%LOCALAPPDATA%\<AppInfo.Name>\collection.json`).

## 4. Feel (maintainer judgment)

- [ ] Frequency, pace, jump distance, visit length: too much, too little, just right?
- [ ] Sounds: too loud, too childish, OK?
