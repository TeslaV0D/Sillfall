# Manual checklist M5 – Snow

Already automated:

- Height field mass conservation, repose angle, max height,
- shedding on close (snow fully on ground), shake, and jerk,
- slow drag carries snow, resize resamples,
- melt until render loop stops, rain speeds melt,
- 0 allocations per frame,
- golden images `snow-light`, `snow-heavy`, `snow-close-up`, `snow-melt`,
- Windows runner: snow render loop and screenshot with/without snow.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Test pattern off, raise “Snow intensity”. For shedding demo without waiting:

```bash
dotnet run --project tools/Weatherly.Sandbox -p:Platform=x64 -- --effect=snow --fill-snow
```

## 1. Visuals

- [ ] Flakes: varied sizes; large ones show shape; natural tumbling.
- [ ] Distant flakes behind windows; near ones land on edges.
- [ ] Piles: soft top, rounded ends, light blue shadow below, occasional glitter.
- [ ] Works on light and dark backgrounds.
- [ ] Full piles shed clumps over window corners.
- [ ] Note dislikes specifically.

## 2. Shedding (real windows)

- [ ] Close or minimize snowy window: snow falls and stays on lower windows or taskbar.
- [ ] Shake: snow flies up and sideways.
- [ ] Slow drag: snow stays and moves with window.
- [ ] Fling and abrupt stop: some snow keeps old velocity. **Check:** Is jerk threshold right? Snow on normal drag = too low; nothing on hard jerk = too high. ADR-0007, §5.
- [ ] Resize: pile adapts.

## 3. Melting

- [ ] Snow to 0: piles gone in ~30 s.
- [ ] Rain and snow together: snow melts faster.
