# Manuelle Checkliste M5 – Schnee

Automatisch geprüft:

- Massenerhaltung des Höhenfelds, Schüttwinkel, Maximalhöhe,
- Abrutschen beim Schließen (der Schnee landet vollständig auf dem Boden), beim Schütteln und beim Ruck,
- langsames Ziehen nimmt den Schnee mit, Resize resampelt,
- Schmelzen bis zum Stopp des Render-Loops, Regen beschleunigt das Schmelzen,
- 0 Allokationen pro Frame,
- Golden-Images `snow-light`, `snow-heavy`, `snow-close-up`, `snow-melt`,
- auf dem Windows-Runner: Render-Loop mit Schnee und ein Screenshot-Vergleich mit und ohne Schnee.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Testmuster aus, „Snow intensity“ hochziehen. Für die Abrutsch-Demo ohne Warten:

```bash
dotnet run --project tools/Weatherly.Sandbox -p:Platform=x64 -- --effect=snow --fill-snow
```

## 1. Optik

- [ ] Flocken: verschiedene Größen, die großen mit erkennbarer Form, sie taumeln natürlich.
- [ ] Ferne Flocken verschwinden hinter Fenstern, nahe landen auf den Kanten.
- [ ] Haufen: weiche Oberkante, abgerundete Enden, leichter Blauschatten unten, gelegentliches Glitzern.
- [ ] Wirkt auf hellem und dunklem Hintergrund.
- [ ] Bei vollem Haufen fallen Klumpen über die Fensterecken.
- [ ] Was nicht gefällt, konkret notieren.

## 2. Abrutschen (echte Fenster)

- [ ] Fenster mit Schnee schließen oder minimieren: Der Schnee fällt herunter und bleibt auf tieferen Fenstern oder der Taskleiste liegen.
- [ ] Fenster schütteln: Der Schnee fliegt hoch und seitlich weg.
- [ ] Fenster langsam ziehen: Der Schnee bleibt liegen und wandert mit.
- [ ] Fenster schnell wegschleudern und abrupt anhalten: Ein Teil des Schnees fliegt weiter.
      **Bitte prüfen:** Ist die Schwelle richtig? Fällt bei normalem Ziehen schon Schnee, ist sie zu niedrig.
      Fällt bei einem kräftigen Ruck nichts, ist sie zu hoch. Siehe ADR-0007, Punkt 5.
- [ ] Fenstergröße ändern: Der Haufen passt sich an.

## 3. Schmelzen

- [ ] Schnee auf 0: Die Haufen schmelzen in etwa einer halben Minute, danach ist alles weg.
- [ ] Schnee und Regen gleichzeitig: Der Schnee schmilzt sichtbar schneller.

## 4. Leistung

Bei 50 % Schnee mit vollen Haufen auf mehreren Fenstern:

- [ ] CPU der App: ______ %
- [ ] GPU der App: ______ %
- [ ] Läuft bei 100 % flüssig: ja / nein
