# Manual checklist M13 – Hardening

Already automated:

- **Core tests:**
  - pause for lock, fullscreen, presentation, RDP, Start/Search, each with setting,
  - crash reports: write, redact, retain, suppress duplicates,
  - soak analysis,
  - ten-minute simulation without memory growth.
- **CI:** 5-minute app soak on every push (artifact `soak` with `soak.csv`).

## 1. Fullscreen and games

- [ ] Exclusive or normal fullscreen game: weather gone. Back within ~2 s after exit.
- [ ] Fullscreen video (browser, Movies & TV): weather pauses.
- [ ] Presentation mode (PowerPoint slideshow): weather pauses.
- [ ] Anti-cheat game does not complain (no injection into other processes).

## 2. Lock, standby, Remote Desktop

- [ ] Win+L, unlock: weather paused then normal, no pop or hitch.
- [ ] Sleep and wake: everything runs. Monitor change (laptop lid, dock): overlay adapts.
- [ ] RDP connect: weather pauses; Advanced toggle keeps it running.
- [ ] Disconnect RDP, local sign-in: as before.

## 3. Start, Search, notifications

- [ ] Start open: weather steps aside, returns on close. Same for Search (Win+S) and notification center (Win+N).
- [ ] Quick settings (Win+A): same.
- [ ] Advanced toggle off: weather stays visible.

## 4. Graphics

- [ ] Restart graphics driver in session (Win+Ctrl+Shift+B): weather back after brief flicker.
- [ ] Dual-GPU laptop: starts and switches cleanly.

## 5. Crash reports

- [ ] Advanced → Open crash reports opens `%LOCALAPPDATA%\<AppInfo.Name>\logs`.
- [ ] If a report exists: no username or profile path in text.

## 6. 8-hour no-leak (sign-off)

On your PC overnight:

```bash
pwsh tools/ci/soak-test.ps1 -Minutes 480
```

- [ ] Run ends with “Soak run passed”.
- [ ] `soak.csv` (temp folder `weatherly-soak`) flat lines for memory, handles, GDI.
- [ ] Note “Soak: … CPU … frame …” row for PLAN.md section 9 budgets (CPU < 3% of one core, GPU frame < 2.5 ms on iGPU).
