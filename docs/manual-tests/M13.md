# Manuelle Checkliste M13 – Härtung

Automatisch geprüft:

- **Core-Tests:**
  - Pausen für Sperre, Vollbild, Präsentation, Remotedesktop, Start/Suche, jeweils mit Einstellung.
  - Fehlerberichte: schreiben, schwärzen, behalten, doppelte unterdrücken.
  - Soak-Auswertung.
  - Zehn Minuten Simulation ohne Speicherwachstum.
- **CI:** 5 Minuten Soak der echten App bei jedem Push (Artefakt `soak` mit `soak.csv`).

## 1. Vollbild und Spiele

- [ ] Ein Spiel im Vollbild (auch exklusiv) starten: Das Wetter verschwindet ganz. Nach dem Beenden ist es nach höchstens 2 Sekunden zurück.
- [ ] Ein Video im Vollbild (Browser, Filme & TV): Das Wetter pausiert.
- [ ] Präsentationsmodus (PowerPoint-Bildschirmpräsentation): Das Wetter pausiert.
- [ ] Ein Spiel mit Anti-Cheat beschwert sich nicht (die App hängt sich in keinen fremden Prozess).

## 2. Sperre, Standby, Remotedesktop

- [ ] Win+L, dann entsperren: Das Wetter pausiert und läuft danach normal weiter, ohne Sprung oder Hänger.
- [ ] Standby und wieder aufwachen: Danach läuft alles. Hat sich der Monitor geändert (Laptop zu, Dock), passt sich das Overlay an.
- [ ] Per Remotedesktop verbinden: Das Wetter pausiert, mit dem Schalter unter „Erweitert“ läuft es weiter.
- [ ] Remotedesktop trennen, lokal wieder anmelden: Alles läuft wie vorher.

## 3. Start, Suche, Benachrichtigungen

- [ ] Startmenü öffnen: Das Wetter tritt zur Seite und kommt beim Schließen zurück. Das gilt auch für die Suche (Win+S) und das Benachrichtigungscenter (Win+N).
- [ ] Schnelleinstellungen (Win+A): dasselbe.
- [ ] Schalter unter „Erweitert“ aus: Das Wetter bleibt sichtbar.

## 4. Grafik

- [ ] Grafiktreiber im Betrieb neu starten (Win+Strg+Umschalt+B): Das Wetter ist nach einem kurzen Flackern wieder da.
- [ ] Laptop mit zwei GPUs: Die App startet und wechselt sauber.

## 5. Fehlerberichte

- [ ] „Erweitert → Fehlerberichte öffnen“ öffnet den Ordner `%LOCALAPPDATA%\Weatherly\logs`.
- [ ] Steht dort ein Bericht: kein Benutzername, kein Profilpfad im Text.

## 6. 8 Stunden ohne Leck (Abnahme)

Auf dem eigenen PC über Nacht:

```bash
pwsh tools/ci/soak-test.ps1 -Minutes 480
```

- [ ] Der Lauf endet mit „Soak run passed“.
- [ ] `soak.csv` (im Temp-Ordner unter `weatherly-soak`) zeigt flache Linien für Speicher, Handles und GDI.
- [ ] Die Werte aus der Zeile „Soak: … CPU … frame …“ für die Budgets notieren (PLAN.md, Abschnitt 9: CPU unter 3 % eines Kerns, GPU-Frame unter 2,5 ms auf einer iGPU).
