# Manual checklist M3 – Engine and tooling

M3 adds the render loop, calibration drops as a test effect, Sandbox, and FrameDump. Real weather effects start at M4.

Already automated (CI):

- Engine: fixed timestep, deterministic, frame-rate independent, 0 allocations in loop,
- live on Windows: 60+ fps on software renderer, 0 bytes allocated per frame, loop stops after turn-off,
- drops visible on app window top edge in desktop screenshot (app moves window to top),
- sprite shapes, blending, Direct2D, golden images with WARP.

## 1. Calibration drops in the app

```bash
dotnet run --project src/Sillfall.App -p:WindowsPackageType=None
```

Enable “Calibration drops”, test pattern off.

- [ ] Drops fall on all monitors and rest on window top edges.
- [ ] Move window with drops: drops move with it.
- [ ] Shake window hard: drops fall off.
- [ ] Close or minimize: drops on that window fall to ground above taskbar.
- [ ] Motion smooth at 60 Hz; note 120/144 Hz if available.
- [ ] Turn drops off: all gone in ~3 s; then GPU 0%.
- [ ] “Window tracking” and other checks stay `OK` (“Check again”).

## 3. Sandbox

```bash
dotnet run --project tools/Sillfall.Sandbox
```

- [ ] Window with dark fake desktop, three draggable fake windows, falling drops.
- [ ] Drag fake windows; clicked one comes forward.
- [ ] `S` shows surface lines, `D` toggles drops, `N` opens window, Delete closes.
- [ ] Left/right arrows change wind; drops drift visibly.
- [ ] Resize sandbox: content adapts.

## 4. FrameDump

```bash
dotnet run --project tools/Sillfall.FrameDump -- --out framedump
```

- [ ] `framedump` contains PNGs per scene and a `*-sheet.png` each.
