# Manual checklist M4 – Rain

Per plan, rain visuals need maintainer sign-off. Already automated:

- Simulation: budget, depth, puddles (mass conservation, resampling), gutters outside frame, waterfalls in heavy rain, splashes do not fall into window, distant drops occluded behind windows, effect fully ends after rain, 0 allocations per frame,
- golden images `rain-light`, `rain-heavy`, `rain-close-up`,
- Windows runner: render loop with rain (fps, 0 allocations, stop after rain) and dry/wet screenshot over app window,
- sound synthesis: level, tone, drop density (runner has no audio device).

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Test pattern off, raise “Rain intensity”.

## 1. Visuals (honest feedback – this is sign-off)

- [ ] Light rain (20–30%): fine, subtle, does not disturb work.
- [ ] Heavy rain (80–100%): dense and dramatic, not flickery.
- [ ] Drops at different depths read clearly (near: thicker, faster, brighter).
- [ ] Distant drops disappear behind windows; near ones land on top edges.
- [ ] Splashes and ripple rings look like water.
- [ ] Water film on top edges visible, not a solid bar.
- [ ] Gutters run outside window sides with a trail.
- [ ] From 85% corners pour continuously.
- [ ] Color works on light and dark backgrounds.
- [ ] Note anything wrong (too bright, too long, too many, …).

## 2. Interaction

- [ ] Move window with puddle: gutters move with it.
- [ ] Shake window: edge water sheds.
- [ ] Close or minimize: water falls; nothing hangs in air.
- [ ] Resize: water film adapts.
- [ ] “Rain depth” 0%: no drops land on windows. 100%: all do.

## 3. Sound

Enable “Rain sound”.

- [ ] Light rain: fine hiss; heavy: fuller rain.
- [ ] Individual drop ticks audible; denser with more impacts.
- [ ] No crackle when moving slider or toggling.
- [ ] Sound off: immediate silence.

- [ ] At 150% or 200%: drops feel same size as at 100%.
