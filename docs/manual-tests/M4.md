# Manuelle Checkliste M4 – Regen

Laut Plan braucht der Regen deine Abnahme der Optik. Automatisch geprüft ist schon:

- Simulation: Budget, Tiefe, Pfützen (Massenerhaltung, Resampling), Rinnsale außerhalb des Rahmens,
  Wasserfälle bei Starkregen, Splashes fallen nicht ins Fenster, ferne Tropfen sind hinter Fenstern
  verdeckt, der Effekt endet nach dem Regen vollständig, 0 Allokationen pro Frame,
- Golden-Images der Szenen `rain-light`, `rain-heavy` und `rain-close-up`,
- auf dem Windows-Runner: Render-Loop mit Regen (fps, 0 Allokationen, Stopp nach dem Regen) und ein
  Screenshot-Vergleich trocken/nass über dem App-Fenster,
- Sound-Synthese: Lautstärke, Klangfarbe, Tropfen-Dichte. Hören konnte das niemand, der Runner hat
  kein Audiogerät.

## Start

```bash
dotnet run --project src/Weatherly.App -p:WindowsPackageType=None
```

Testmuster aus, „Rain intensity“ hochziehen.

## 1. Optik (bitte mit Ehrlichkeit, das ist die Abnahme)

- [ ] Leichter Regen (20–30 %): fein, dezent, stört beim Arbeiten nicht.
- [ ] Starker Regen (80–100 %): dicht und dramatisch, aber nicht flimmernd.
- [ ] Tropfen in verschiedenen Tiefen sind erkennbar (nah: dicker, schneller, heller).
- [ ] Ferne Tropfen verschwinden hinter Fenstern, nahe landen auf den Oberkanten.
- [ ] Splashes und Ripple-Ringe beim Aufprall sehen nach Wasser aus.
- [ ] Wasserfilm auf den Fensteroberkanten: sichtbar, aber nicht wie ein Balken.
- [ ] Rinnsale laufen außen an den Fensterseiten herunter, mit Spur.
- [ ] Ab 85 % gießt es aus den Fensterecken.
- [ ] Farbe passt auf hellem und dunklem Hintergrund (helles Fenster, dunkler Desktop).
- [ ] Was dir nicht gefällt, bitte konkret notieren (zu hell, zu lang, zu viele, …).

## 2. Interaktion

- [ ] Fenster mit Pfütze verschieben: Rinnsale wandern mit.
- [ ] Fenster schütteln: Das Wasser auf der Kante fällt ab.
- [ ] Fenster schließen oder minimieren: Wasser fällt herunter, nichts bleibt in der Luft hängen.
- [ ] Fenstergröße ändern: Der Wasserfilm passt sich an.
- [ ] „Rain depth“ auf 0 %: Kein Tropfen landet mehr auf Fenstern. Auf 100 %: alle.

## 3. Sound

„Rain sound“ einschalten.

- [ ] Leichter Regen klingt nach feinem Rauschen, starker nach vollem Regen.
- [ ] Einzelne Tropfen-Ticks sind hörbar, dichter bei mehr Aufprallen.
- [ ] Kein Knacken beim Verschieben des Reglers oder beim Ein-/Ausschalten.
- [ ] Sound aus: sofort still.

## 4. Leistung (Referenz PLAN.md, Abschnitt 9: iGPU, 1440p, 60 fps, alle Effekte 50 %)

Bei 50 % Regen im Task-Manager notieren:

- [ ] CPU der App: ______ % (Ziel < 3 % eines Kerns)
- [ ] GPU der App: ______ %
- [ ] RAM: ______ MB (Ziel < 150 MB)
- [ ] Bei 100 % Regen läuft es noch flüssig: ja / nein

## 5. Mehrere Monitore, Skalierung

- [ ] Regen auf allen Monitoren, keine Naht an den Monitorgrenzen.
- [ ] Bei 150 % oder 200 %: Tropfen wirken gleich groß wie bei 100 %.
- [ ] Gemischte Skalierung (z. B. 100 % und 150 %): Wirkt der Regen auf beiden stimmig? (Siehe ADR-0006, Punkt 4.)
