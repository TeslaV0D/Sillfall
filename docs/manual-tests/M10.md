# Manual checklist M10 – Weather sync

Already automated (Core tests, CI):

- Mapping table (one row, one test), invert, day/night from sun position,
- read MET responses, caching (`If-Modified-Since`, `Expires`), errors (offline, timeout, 403/429/500, bad JSON),
- schedule (15–60 min, backoff to 30 min, offline keeps last forecast),
- location rounded to one decimal before send (privacy test),
- per-element blend, pause on manual override, frost keeps snow,
- offline city search (München/Muenchen/Munich, Köln/Koeln, “Vienna, US”).

Smoke test never enables sync or uses the network.

## 1. Sync with a city

- [ ] Settings, Weather sync: enable “Follow the real weather”.
- [ ] Type “Hamb” under City: Hamburg appears immediately (no network).
- [ ] Select Hamburg.
- [ ] Within seconds “Now” shows weather (symbol, °C, wind) and next fetch time.
- [ ] Desktop weather roughly matches outside or a weather app. Too strong or weak?

## 2. This PC’s location

- [ ] Location “This PC's location”: Windows permission prompt.
- [ ] Allow: approximate position (one decimal) with weather.
- [ ] Deny (or disable in Windows): message explains how to allow. App continues.

## 3. Manual override

- [ ] With sync on, move rain slider: banner “Weather sync paused” names rain.
- [ ] Rain stays at manual value; other effects still follow weather.
- [ ] “Resume sync”: rain follows weather again.
- [ ] Rain weight 50%: between manual and weather.
- [ ] Invert on: clear sky rains; rain brings sun (daytime).

## 4. Offline

- [ ] Wi‑Fi off and “Update now”: status “Offline”; effects use last forecast.
- [ ] Wi‑Fi on: status updates by shown time at latest.

## 5. Frost (cold weather or invert on a hot day)

- [ ] ≤ 2 °C: snow stays after snowfall stops. Above 2 °C it melts.

## 6. Privacy and credits

- [ ] About and sync pages name MET Norway and GeoNames.
- [ ] Optional proxy/Fiddler: only `api.met.no`, lat/lon one decimal. Nothing when sync off.
